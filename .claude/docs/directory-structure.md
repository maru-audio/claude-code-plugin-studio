## Project structure

```
src/index.ts          authoring entry: exports the module declaration
src/contract.ts       parameter schema, the owner of names, ranges and tapers
src/factory-bank.ts   factory presets
src/qualification.ts  deterministic audio and automation tapes
src/dsp/              the Processor: this is where the sound is
src/ui/               the face, from public UI kit controls
design/               brief, signal flow, Sound Bible, Face Bible, PDDs, UX
docs/                 how-to guides, workflow guide, architecture, manual
production/           sprints, stories, bugs, QA evidence, validation, gaps
tests/ tools/ assets/ demos/ prototypes/
```
