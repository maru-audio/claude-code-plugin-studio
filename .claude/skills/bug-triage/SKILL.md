# Bug Triage

Re-evaluate open bugs: priority against severity, and what is a systemic trend.

## Who leads

`qa-lead`

## Steps

1. Read `production/bugs/`.
2. Rank by harm to the musician.
3. Name patterns.
4. Recommend what to fix next.

## Done when

Bugs are ranked with a next recommendation.
